## ✨ Funcionalidades

- **Página inicial** com apresentação da clínica, diferenciais, equipe e contato
- **Catálogo de tratamentos**: clareamento, implante, ortodontia, canal, estética facial, limpeza, restauração e cirurgia
- **Telas de Login, Cadastro e Agendamento** (seleção de serviço e data)
- **Navegação sem recarregar a página**: as seções são exibidas/ocultadas via JavaScript
- **Layout responsivo** com breakpoints em 980, 860, 700 e 420 px
- **Menu hambúrguer** no mobile, que fecha ao navegar, ao clicar fora ou ao ampliar a janela

> Projeto de front-end: os formulários são apenas de interface e não enviam dados para um servidor.

## 🚀 Como executar

Acesse a **[demo online](https://beatrizxx06.github.io/Clinica_Odontologica/)** ou clone o repositório e abra o `index.html` no navegador:

```bash
git clone https://github.com/Beatrizxx06/Clinica_Odontologica.git
```

## 🧠 Aprendizados

- Layout responsivo com media queries
- Manipulação do DOM para navegação entre seções
- Acessibilidade básica (`aria-label` na navegação)
